## Steps
- Stop the currently running dev server process.
- Start a fresh dev server on port 3003.
- Verify readiness and share the access URLs.

## Commands
- Stop: terminate the existing dev server process.
- Start: `npm run dev -- -p 3003`
- Verify: check status and ensure it reports Ready with `.env.local` loaded.

## Outcome
- Server running on `http://localhost:3003` with clean state.
